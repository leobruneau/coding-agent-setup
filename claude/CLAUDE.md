# Writing

The unslop skill below is always loaded. Apply it to all prose you write or edit, in every project and every session, without being asked: replies, documents, letters, emails, READMEs, UI copy, code comments, commit messages and PR descriptions. Check the text against its rules before delivering. You don't need to invoke the skill, because its rules are already in context.

When spawning Explore subagents, pass `model: "haiku"`.

@skills/unslop/SKILL.md

When reporting technical information to me (code, commands, builds, tool output), be extremely concise and sacrifice grammar for the sake of concision. This overrides unslop rule 33 for those reports only. For everything else, be concise but keep full grammar and apply unslop as written.
